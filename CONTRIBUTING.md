# Contributing to Pediatric Simulation Trainer

We appreciate contributions! Here's how to get started:

## Development Workflow

1. **Fork and Clone**
   ```bash
   git clone https://github.com/yourusername/pediatric-simulation-trainer.git
   cd pediatric-simulation-trainer
   ```

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Follow the existing code style
   - Add tests for new features
   - Update documentation as needed

4. **Commit and Push**
   ```bash
   git commit -m "feat: description of changes"
   git push origin feature/your-feature-name
   ```

5. **Create a Pull Request**

## Code Style

- Use ESLint for JavaScript/React
- Follow existing folder structure
- Write meaningful commit messages
- Add comments for complex logic

## Reporting Issues

Use GitHub Issues with:
- Clear title and description
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Questions?

Open a discussion or contact the maintainers.
